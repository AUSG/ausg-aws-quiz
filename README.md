# AWS 상식 퀴즈

대학생 해커톤 **부스용** AWS 퀴즈. AWS Certified Cloud Practitioner(CLF-C02) 수준으로,
한 명당 3문제 약 30초. **3문제를 전부 맞혀야 상품**을 받는다.

**https://ausg-aws-quiz.vercel.app**

- 백엔드·데이터베이스·환경 변수가 없다. 정적 SPA 하나가 전부다.
- PWA로 자산을 캐시하므로 **첫 로딩 후에는 행사장 네트워크가 끊겨도 계속 동작한다.**
- 개인정보를 수집하지 않는다. 재도전 방지 장치도 없다(의도된 것 — 부스에서는 옆에 선 스태프가 그 역할을 한다).

## 설계 전제

부스는 공부 도구가 아니다. 모르는 사람이 지나가다 태블릿을 집어 들고 30초를 쓰고 떠난다.

- **제출 버튼이 없다.** 보기를 누르면 즉시 채점된다. 문항당 탭 3회 → 2회.
- **난이도 오름차순으로 출제된다.** 첫 문제에서 틀린 방문자는 태블릿을 내려놓기 때문이다.
- **1번 문제는 항상 커뮤니티 문제다.** 부스에서 방금 들은 AUSG·AWSKRUG 이야기가
  첫 문제로 다시 나와야 소개와 퀴즈가 한 흐름이 된다.
- **60초 무입력 시 자동으로 초기화된다.** 다음 방문자가 앞사람 점수를 보지 않도록.

각 결정의 자세한 근거는 해당 소스 파일 주석에 있다.

## 현장 튜닝

URL 파라미터로 바꾼다. 재배포가 필요 없다.

| 파라미터 | 기본값 | 설명 |
|---|---|---|
| `?n=` | 3 | 문항 수 (3~10) |
| `?prize=` | 3 | 상품 커트라인 (문항 수를 넘지 못함) |
| `?idle=` | 60 | 자동 초기화 초. `0`이면 끔 |
| `?hint=` | 700 | 힌트 공개 지연 밀리초(0~3000). `0`이면 즉시 |
| `?kiosk=` | 1 | `0`이면 키오스크 모드 해제 |

**`?prize=2`가 현장에서 제일 자주 쓸 카드다.** 기본값은 3문제 전부 정답이라 커트라인이 높다.
상품을 받아 가는 사람이 눈에 띄게 적으면 이걸로 낮춘다.

```
https://ausg-aws-quiz.vercel.app/?prize=2
https://ausg-aws-quiz.vercel.app/?idle=0     ← 시연 등 자동 초기화가 방해될 때
https://ausg-aws-quiz.vercel.app/?hint=0     ← 대기줄이 길어 0.7초도 아까울 때
```

## 개발

```bash
nvm use          # Node 22
npm install
npm run dev      # http://localhost:5173
npm test
npm run build    # Vercel이 실행하는 것과 같은 명령
```

푸시 전에 `npm run build`가 로컬에서 통과해야 한다. 여기서 깨지면 배포도 깨진다.

## 문제 추가하기

`src/data/questions.ts`에 추가한다. `src/data/validateBank.ts`가 길이 제한과
정답 위치 분포, 카테고리별 난이도 커버리지를 강제하고 `npm test`가 실제 문제 은행을 검증한다.

카테고리는 커뮤니티 + AWS 6개다. 커뮤니티만 난이도 1 문항을 4개 두는데, 이 카테고리가
매 세션 1번 자리를 고정으로 가져가서 얕으면 앞사람과 같은 첫 문제가 반복되기 때문이다.

힌트는 **Codex 힌트** 버튼으로 열린다. 각 문항의 `hint` 필드에 미리 적어둔 문장이며
실행 중에 무언가를 생성하거나 호출하지 않는다 — 부스는 네트워크 없이도 돌아야 한다.

길이 제한(문제 60자 / 보기 24자 / 해설 70자)은 콘텐츠 규칙이 아니라 **레이아웃 규칙**이다.
넘기면 폰에서 스크롤이 생기고, 부스에서 스크롤은 곧 이탈이다.

한글 폰트는 실제로 쓰는 글자만 남긴 서브셋이다. 새 글자가 들어가면
`fontCoverage` 테스트가 실패하며, `python3 scripts/build-fonts.py`로 재생성하면 된다.

## 배포

`main`에 푸시하면 Vercel이 자동 배포한다. 문제가 생기면 고치려 들지 말고
Vercel 대시보드 → Deployments → **Instant Rollback**으로 먼저 되돌린다.
